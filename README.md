## 0. 仓库
- 地址：https://github.com/zhangxudun/cfd （私有，分支 main，Python 3.11）
- 克隆：git clone https://github.com/zhangxudun/cfd.git
- 开工前先读 README.md 及全部现有脚本和 tests/。
- 提交方式：新建分支 → PR 到 main，CI（.github/workflows/test.yml）必须全绿。

## 1. 目标
把现有“省煤器单一几何”扩展为“多种电厂几何”的统一流程：
几何描述(dict) → 三维几何+网格 → 边界条件文件 → 换热计算 → 结果校验。
每一步都要有 pytest 自动测试。

## 2. 沿用的约定（不得破坏）
- 坐标：x 宽度，y 深度，z 高度；单位 SI，温度 K。
- 输入为中文键字典；输出文件名必须是 ASCII。
- 非法输入一律抛 ValueError。
- 现有 tests/test_model.py、tests/test_cfd.py 必须继续通过。
- 依赖只用 gmsh、numpy、scipy、matplotlib、pytest；新增依赖须在 PR 中说明。

## 3. 需支持的几何（每种一个“类型”值）
| 编号 | 类型 | 代表设备 | 关键参数 |
|---|---|---|---|
| G1 | 多孔管束 | 省煤器、低温过热器/再热器 | 半宽x、深度y、管束高度、入口/出口段长度、孔隙率 |
| G2 | 直烟道 | 矩形/圆形烟风道 | 截面尺寸、长度 |
| G3 | 弯头烟道 | 90° 弯头 | 截面尺寸、弯曲半径、前后直段长度 |
| G4 | 变径段 | 扩散/收缩段 | 进出口截面、长度 |
| G5 | 圆筒壁 | 单管、集箱、汽包壁（固体导热） | 内径、外径、长度 |
| G6 | 管壳式 | 凝汽器、加热器（壳侧多孔简化） | 壳体直径、长度、管束区范围、进出口接管 |
