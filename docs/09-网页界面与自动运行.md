# 网页界面与自动运行

`app.py` 是本地网页界面：上传 STEP（或用内置结构 S1–S3 生成），核对面类型和多孔体，填工况，然后由 `auto_run.py` 自动跑第 2–8 步。出错时按第 3 节的规则自动改网格、步数或时限后重跑；通过后再做网格无关性检查。

## 1. 启动

计算要用 OpenFOAM，所以界面在本机或 Codespaces 里运行，不能做成静态网页。

```bash
pip install gmsh streamlit plotly
streamlit run app.py          # 在仓库根目录执行，然后打开 http://localhost:8501
```

- 默认用 docker 运行 `opencfd/openfoam-default:2412`（第一次会自动下载镜像，约 1 GB）。Windows / macOS 装 Docker Desktop 并启动即可。界面里“检查运行环境”按钮会确认 docker 和镜像。
- 已装 OpenFOAM 的 Linux 可以在“运行方式”里选“本机”。
- 每次计算的文件放在 `运行目录/<时间>-<编号>/`（已加入 `.gitignore`），可用环境变量 `ZXDCFD_WORKDIR` 改位置。

## 2. 界面上的步骤

| 区块 | 做什么 | 说明 |
|---|---|---|
| 1 几何 | 上传 `.step/.stp`，或选内置结构填参数后生成 | 单位按 m；内置 S3 自动套用结构卡片给的标注（入口在侧面） |
| 2 边界 | 三维图按类型着色、标面编号；表格里逐个改面类型；选多孔体；可上传 `标注.json` | 自动识别规则与第 2 步相同；内部面（interface）只显示不可改；没有 inlet 或 outlet 时不能开始计算 |
| 3 工况 | 入口速度和温度、出口表压、物性、壁面；有多孔体时填阻力和换热（温差或定热源） | 可上传 / 下载 `工况.json`；默认值与 `tests/test_end_to_end.py` 相同，只是“合理但人为”的起点 |
| 4 计算设置 | 网格尺寸（0 = 对角线 / 30）、步数、单元上限、最多返工、网格无关性、对照一维、运行方式、时限 | 对照一维只适用于等截面、来流均匀的多孔区（如 S1） |
| 5 运行 | 调用 `auto_run.auto_run`，实时显示每一步 | |
| 6 结果 | 结论、压差 / 出口温度 / 吸热量、第 7 步检查表、网格无关性表、每次运行及自动修改、残差和监测曲线；下载最终算例 zip、报告、总结 json | 输入在计算后改过时提示结果已过期 |

## 3. 自动返工规则

每一层网格最多返工 `最多返工` 次（默认 4）。第 8 步给出“返工”时，按下表先后找第一条适用的改法：

| 现象（第 8 步的原因） | 自动修改 | 停下的条件 |
|---|---|---|
| 校验错误、标注错误、工况错误、算例错误、几何错误 | 不改，要人工 | 立即：这些是输入问题 |
| 找不到 docker、环境里找不到 OpenFOAM、启动不了 | 不改，要人工 | 立即：运行环境问题 |
| 求解超时 | 时限 ×2 | 时限超过 7200 秒 |
| checkMesh 不通过、网格体积偏差超限（网格错误） | 网格尺寸 ×0.75 | 估计单元数超过上限 |
| 其他求解报错（多为发散） | 网格尺寸 ×0.75，只试一次 | 第二次仍报错 |
| 结果错误（读不到结果） | 原设置重跑一次 | 第二次仍报错 |
| 流量守恒、监测值稳定、残差收敛不通过 | 步数 ×2（到 6400 为止）；已提前收敛或步数到头时网格尺寸 ×0.75 | 估计单元数超过上限 |
| 入口流量与理论值不符 | 网格尺寸 ×0.75，只试一次 | 第二次仍不符：多半是入口面标错或入口速度不对 |
| 与一维估算不一致 | 网格尺寸 ×0.75，只试一次 | 第二次仍不符：多半是一维估算不适用（变截面、转弯入口）或多孔体、流向不对 |

加密前按“单元数 ∝ 1 / 尺寸³”估计新网格的单元数，超过 `单元上限`（默认 400000）就停下。勾了对照一维但几何没有一维估算值时，第 7 步自动改为只做四项基本检查。

## 4. 网格无关性

基准网格通过第 8 步后，网格尺寸除以 1.4（单元数约 ×2.7）再跑一层，同样带自动返工。与上一层相比：

- 进出口压差相对变化不超过 3%，
- 吸热量相对变化不超过 2%，

两项都满足就结束，取较细一层为结果；否则继续加密，最多 3 层。下一层估计超过单元上限时停下，结论为“网格无关性未确认”，界面显示最后一次通过的结果，并提示调高上限后重算。

## 5. 结论

| 结论 | 含义 |
|---|---|
| 通过 | 第 7 步各项检查通过；勾选网格无关性时，最后两层网格的结果在容差内 |
| 网格无关性未确认 | 结果通过第 7 步，但加密到单元上限仍没确认与网格无关 |
| 需要人工 | 输入或环境问题，或自动改法用完后仍不通过且原因指向输入 |
| 未通过 | 返工次数用完 |

## 6. 结果可信到什么程度

自动保证的是数值上的可信：求解跑完、残差和监测值稳定、流量守恒、入口流量正确、结果与网格无关。物理模型本身不能自动保证：不可压且密度取入口温度下的值，层流加常数湍流粘度，外壁绝热，多孔阻力和换热系数由用户给定，默认壁面滑移。进出口压差是静压差，入口和出口流速不同时含动压变化。转弯、分离、导流板一类问题对湍流模型敏感，这个模型只能看趋势。结果是否准确，最终要和实测或可靠的设计计算对比。

## 7. 测试

- `tests/test_auto_run.py`：AR-01 至 AR-09 用替身代替第 4–7 步，逐条检查第 3、4 节的规则；AR-10 用容器对 S3 真跑一次（单元上限 150000），报告写到 `AUTO_RUN_REPORT`，CI 发布为 `auto-run-report.txt`。
- `tests/test_app.py`：用 `streamlit.testing.v1.AppTest` 检查界面能生成 S1、S3 几何、识别面，并把输入原样交给 `auto_run`。
