# 流程 3：换热计算

> 原文 4.3 节。公共约定、几何类型表（G1–G6）、交付物和完成标准见 [README](../README.md)。
> 上一流程：[02-边界条件](02-边界条件.md)

## 功能需求
- 入口函数：运行(工况) → 结果字典（出口温度、压降、换热量、进/出口质量流量、是否收敛）。

## 测试点（粗网格，单例 ≤ 60 s）
- T-H-01 质量守恒：进出口质量流量相对差 ≤ 1e-6。
- T-H-02 能量守恒：换热量 与 m·cp·(T进−T出) 相对差 ≤ 1%。
- T-H-03 G1：三维解与一维参考解对比，压降误差 ≤ 2%，出口温度差 ≤ 2 K。
- T-H-04 G2 绝热壁：出口温度 = 入口温度（差 ≤ 0.1 K）。
- T-H-05 G5：与圆筒壁稳态导热解析解 q=2πkL·ΔT/ln(r2/r1) 对比，误差 ≤ 3%。
- T-H-06 G3/G4/G6：能收敛，且满足 T-H-01、T-H-02。
- T-H-07 定热源模式：温降与 Q/(m·cp) 的差 ≤ 2%。
- T-H-08 输出 vtk/csv/png 非空，csv 列名与 README 约定一致。

## 完成标准中与本流程相关的要求
- 6 种几何各至少覆盖 T-H-01、T-H-02。
