# 流程 2：边界条件

> 原文 4.2 节。公共约定、几何类型表（G1–G6）、交付物和完成标准见 [README](../README.md)。
> 上一流程：[01-几何与网格](01-几何与网格.md)　下一流程：[03-换热计算](03-换热计算.md)

## 功能需求
- 入口函数：生成边界条件(描述, 工况) → 写 <前缀>_bc.json。
- 支持类型：速度入口、压力出口、对称、壁面（绝热/定壁温/定热流/对流 h+T∞）、
  内部面 interior、多孔区（阻力系数+体积换热或定热源）。

## 测试点
- T-B-01 每个面物理组恰好对应一条边界条件，无缺漏、无多余。
- T-B-02 字段完整且单位为 SI（入口必须有速度和温度，出口必须有表压）。
- T-B-03 非法组合被拒绝：无入口或无出口、温度 ≤0 K、定壁温缺温度值等。
- T-B-04 JSON 可回读，且回读后与输入工况一致。
- T-B-05 可由同一 JSON 生成 OpenFOAM 的 0/ 目录边界文件，边界名与网格一致。

## 完成标准中与本流程相关的要求
- 6 种几何各至少覆盖 T-B-01。
