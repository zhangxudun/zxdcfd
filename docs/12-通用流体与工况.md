# 通用流体与工况

> 实现：`generate_boundary.py`（工况校验、按流向识别）、`generate_case.py`（物性、壁面条件）、`ui_tools.py` / `app.py`（网页表单）。
> 测试：`tests/test_generic_fluid.py`（GF-01 至 GF-11），`tests/test_turbulence.py`（TB-01 至 TB-08），`tests/test_app.py` 的 UI-07。

原来的流程是按电厂烟道写的：物性固定按空气类理想气体（Sutherland 粘度、Pr = 0.7），流动固定沿 -z，入口、出口固定是最高、最低的水平面，外壁只能绝热，管束壁温按“顶部 / 底部”给。这些对水、油、其他气体和任意朝向的设备都不适用，现已改成通用写法。旧的工况文件不用改，含义不变。

## 1. 物性（单相牛顿流体，按入口温度取常数）

| 项目 | 写法一 | 写法二 | 不填时 |
|---|---|---|---|
| 密度 | `密度` kg/m³（常数，液体） | `工作压力` Pa + `摩尔质量` kg/mol（理想气体） | 必须选一种 |
| 分子粘度 | `分子粘度` Pa·s（常数） | Sutherland：`萨瑟兰参考粘度`、`萨瑟兰参考温度`、`萨瑟兰常数` | Sutherland，空气系数 |
| 分子导热 | `导热系数` W/(m·K) | `分子普朗特数` | 理想气体取 Pr = 0.7；常数密度必须填 |
| 比热 | `比热` J/(kg·K) | — | 必须填 |
| 附加湍流粘度 | `湍流粘度` Pa·s，`湍流普朗特数` | — | 0（纯层流），0.9 |

同时给两种写法会报错，避免“填了密度却仍按理想气体算”。网页上可以从预设起步：示例高温气体（原默认值）、空气、水（20 °C）、导热油（约 100 °C，示意）。液体预设是某一温度下的常数，入口温度差得远时要按实际温度重新查表。

## 2. 流向与自动识别

- 工况 `流向`：主流方向，三个数，不填为 (0, 0, -1)。网页第 2 步可选 ±x、±y、±z 或自定义。
- inlet：垂直于流向、位于最上游的平面；outlet：最下游的平面。流向与坐标轴平行时用包围盒判断（与原规则在 -z 时完全一致），斜向时在面上取样判断。
- symmetry：x=0 且是模型最小 x 的平面，只在流向与该平面平行时才这样猜（流向沿 x 时 x=0 是入口，不是对称面）。
- 三个实体时，沿流向排在中间的那个猜成多孔体。多孔阻力的主方向、一维估算、压力截面都跟着流向。

## 3. 壁面换热

`壁面换热` 不填为绝热。`{'方式': '定壁温', '壁温': K}` 写成 fixedValue；`{'方式': '定热流', '热流密度': W/m²}`（流入流体为正）写成 fixedGradient，梯度 = q / 有效导热系数。所有 walls 共用一个条件。

## 4. 多孔区

“多孔区”不限于管束：填料床、滤网、换热芯体、整流格栅都按 Darcy–Forchheimer 处理。温差换热的壁温可以是均匀的 `壁温`，或沿流向线性的 `壁温入口侧` + `壁温出口侧`；旧名 `壁温顶部` / `壁温底部` 仍然认，含义就是入口侧 / 出口侧。

## 5. 慢流的温度收敛

液体或低速流的停留时间（体积 / 流量）可以是几十到几百秒。温度方程的伪时间步原来固定 1 s，流场收敛后 simpleFoam 提前停算，温度还没稳定。现在停留时间超过 20 s 时自动放大伪时间步（见 [写算例](05-写算例.md)），气体算例不变。

## 6. 水侧耦合（省煤器、换热器）

“温差”方式的壁温要人工给，相当于事先知道水温分布。`多孔.换热.方式 = '水侧耦合'` 时，管内工质（水或其他单相流体）的温度由能量平衡算出，烟气侧和水侧一起收敛。

| 项 | 键 | 说明 |
|---|---|---|
| 水入口 | `水入口温度` K，`水质量流量` kg/s，`水比热` J/(kg·K) | 必填 |
| 流动方向 | `水流动`: `逆流`（默认）/ `顺流` | 逆流: 水从多孔区流出端进、流入端出 |
| 换热系数（二选一） | `h_av` W/(m³·K) | 烟气到水的总体积换热系数，已含管壁和水侧 |
| | `管束`: `单位体积换热面积` m²/m³、`烟气侧换热系数`、`水侧换热系数` W/(m²·K)、`管外径`、`管内径` m、`管壁导热系数` W/(m·K)、`污垢热阻` m²·K/W（默认 0） | 都以管外表面计串联: 1/U = 1/h烟 + R污 + d外·ln(d外/d内)/(2λ) + d外/(d内·h水)，h_av = a·U |
| 可选 | `水饱和温度` K | 给了时第 7 步检查水温最高值低于它 |
| 可选 | `分段数`（默认 40） | 水侧沿流向的分段 |

做法（第 5 步写进温度方程的 `scalarCodedSource`，OpenFOAM 运行时编译）：多孔区沿主流方向分成 N 段，每个伪时间步用当前烟气温度算每段烟气传给水的热量，从水入口一端逐段推出节点水温（对烟气温度线性化，比直接推稳），单元水温在两节点间插值；源项 k·(Tw − T) 的 −k·T 放进对角线。每步的水出口温度和换热量写进 `postProcessing/waterSide.dat`，最后的水温分布写进 `waterProfile.dat`。

第 7 步在四项基本检查后加三项：水侧稳定（水出口温度最后 51 行变化 < 0.01 K，水侧前后两步换热量差 < 0.1%）、热平衡（外壁绝热时，烟气按进出口温度算的放热与水吸热差 < 1%）、水未沸腾。对照一维时一维解改用 ε-NTU（逆流 / 顺流），并加“水出口温度与一维解一致”（偏差 < 估算温升的 3%）。

假设和限制：
- 同一截面上水温相同（水沿主流方向一维），即管排按逆流或顺流整体布置；不区分各根管子、各个回程，叉流的具体管程没有建模。
- 管壁热容、管壁沿程导热不计（稳态），管壁热阻按圆筒径向导热并到总热阻里。
- 换热系数是常数，不随当地流速变化；水侧单相，不能沸腾（给 `水饱和温度` 来检查）。
- 需要 OpenFOAM 环境能编译（opencfd/openfoam-default 镜像带编译器）；第一次运行多花几十秒。

## 7. 多孔压降偏低（已知，未解决）

CI 实测：多孔区压差比一维解 L·(粘性阻力系数·μ·U + 惯性阻力系数·ρU²/2) 系统性偏低，与流体种类无关，阻力越强偏得越多，加密网格只缓慢减小，与多孔区长度近似成正比（不是两端的端部效应）。

| 算例（水，+x，2 m 多孔床） | 网格 m | 偏低 |
|---|---|---|
| 粘性 1e6 + 惯性 100 | 0.08 / 0.04 / 0.025 | 4.0% / 3.6% / 3.1% |
| 只有粘性 1e6 | 0.04 | 1.3% |
| 只有惯性 100 | 0.04 | 3.6% |
| 粘性 1e5 + 惯性 10（GF-10 用的） | 0.04 | 0.95% |
| 内置 S1 / S2 / S3（气体） | 默认 | 2.3% / 1.8% / 2.6% |

所以阻力很强的多孔区（例如密实填料床里的液体），“压差与一维解一致”这一项可能超过 3% 而不通过。原因还没查清（怀疑与四面体网格上强源项的压力–速度耦合有关），检查阈值没有放宽。

## 8. 结果的说法

- 第 7 步一维对照的检查项改名为“出口温度与一维解一致”（原“出口烟温与一维解一致”）；第 8 步仍认旧版 `结果.json` 里的旧名。
- `吸热量` 键名不变，含义是流体放出的热量 ρ·Q·cp·(T入 − T出)，流体被加热时为负。网页上显示为“换热量（流体放热为正）”，单位 kW。

## 9. 湍流模型（RANS + 壁面函数）

原来只有层流加一个全场常数的“湍流粘度”，不能算壁面摩擦、近壁换热和湍流掺混。现在工况里加 `湍流` 项：

| 键 | 取值 | 不填时 |
|---|---|---|
| `模型` | `层流` / `k-ε` / `realizable k-ε` / `k-ω SST` | 没有 `湍流` 项时是层流（旧工况文件含义不变）；网页默认 k-ω SST |
| `湍流强度` | 入口 I，(0, 1) | 0.05 |
| `混合长度` | 入口湍流长度尺度 l，m | 0.07 × 入口当量直径（4A/P，A、P 取 inlet 面的面积和周长） |

- 入口：k = 1.5 (U·I)²，ε = Cμ^0.75 k^1.5 / l，ω = √k / (Cμ^0.25 l)，Cμ = 0.09；OpenFOAM 里用 `turbulentIntensityKineticEnergyInlet`、`turbulentMixingLength…Inlet`。
- 壁面无滑移：`kqRWallFunction`、`epsilonWallFunction` / `omegaWallFunction`、`nutkWallFunction`；壁面滑移时 k、ε、ω 取零梯度，不用壁面函数。
- 温度：湍流扩散按 α_eff = α + ν_t / Pr_t（`scalarTransport` 的 alphaD、alphaDt）；外壁定热流时按逐面的 α_eff 换算梯度，保证总热流是 q·A。选了模型以后不能再填常数湍流粘度。
- 第 5 步在 `算例信息.json` 的 `湍流` 里写出入口当量直径、入口雷诺数、k、ε、ω 和流态提示（选了模型但 Re < 2300，或层流但 Re > 4000 时提醒）。
- 第 7 步在 `结果.json` 里写 `湍流模型`、`壁面yPlus`（最小 / 最大 / 平均）、`边界层` 和 `近壁说明`。y+ 不是通过条件，只给说明：壁面函数适用于 y+ 约 11–300。

### 9.1 四面体网格要加棱柱边界层

gmsh 生成的是纯四面体。用 0.1 m 方管、空气 10 m/s（Re ≈ 6.4×10⁴）实算，充分发展段的压力梯度与光滑管 Haaland 公式对比：

| 网格 | 模型 | 压力梯度 / Haaland |
|---|---|---|
| 纯四面体 h = 12.5 mm / 8.3 mm | k-ω SST | 0.62 / 0.60 |
| 纯四面体 | k-ε | 0.61 |
| 六面体（blockMesh 8×8×160、12×12×240） | k-ω SST、k-ε | 1.00 |
| 四面体 + 3 层棱柱层（h = 12.5 mm / 20 mm） | k-ω SST | 0.89 / 0.93 |
| 四面体 + 3 层棱柱层 | k-ε | 0.95 |
| 四面体 + 5 层棱柱层（h = 20 mm） | k-ω SST | 0.87 |

六面体网格上与关联式一致，说明模型和边界条件写法是对的；问题在四面体近壁单元的壁面距离和梯度重构，壁面摩擦偏低约 40%。gmsh 4.15 没有三维边界层，所以流程在选了湍流模型且壁面无滑移时，于 gmshToFoam 之后用 `snappyHexMesh` 只做 addLayers，在 walls 上挤出 3 层棱柱层（相对厚度、末层 0.4、增长率 1.2），再做 checkMesh。多孔分区（porous_zone）加层后保留（TB-08）。第 7 步从 `log.snappyHexMesh` 读出实际加上的平均层数，不足目标的 80% 时在近壁说明里提醒。

仍需注意：加层后壁面摩擦仍偏低 5–13%；y+ 落在 11–30 的对数律下端；复杂几何的尖角处 snappyHexMesh 可能少加或不加层；壁面函数不适合分离、强逆压梯度和低雷诺数流动。

### 9.2 收敛判据的一处调整

慢流（如 0.05 m/s 的水）里 k、ε 要很多步才输运到下游，残差会在 1e-3 以上走一段平台，最后几十步才降到 1e-6。simpleFoam 按 residualControl（各方程 1e-6）提前结束时，51 步窗口里还留着平台段。这种情况第 7 步改为看最后一步每个方程 < 1e-3，并且窗口里超过 1e-3 的方程从最大值以后没有回升超过 10 倍；跑满步数没有提前收敛时，仍按原来的 51 步窗口判（`tests/test_check_result.py` 的 T7-46）。

## 10. 仍不适用的情况

可压缩流动（马赫数大于约 0.3 或压降与绝对压力相比不小）、物性随温度显著变化、浮升力 / 自然对流、两相与相变、燃烧与化学反应、辐射、非牛顿流体、LES / DES 等尺度解析湍流、低雷诺数近壁求解（y+ ≈ 1）。这些需要换求解器或另加网格功能，不在当前流程内。
