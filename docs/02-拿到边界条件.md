# 第 2 步测试需求：拿到边界条件

> 对应 [工作流程](工作流程.md) 第 2 步。
> 产物：`标注.json`、工况字典。通过条件：每个外表面都有类型，入口和出口有数值。

## 1. 范围

- 测：面类型自动识别、多孔体自动识别、标注覆盖、`标注.json` 读写、工况字典数值是否齐全。
- 不测：STEP 读入和 fragment（第 1 步）、有没有 inlet/outlet 以及内部面是否被设成边界（第 3 步）、网格（第 4 步）。

## 2. 测试几何

| 编号 | 几何 | 说明 |
|---|---|---|
| A | 长方体 1 × 2 × 3 m，单实体，x∈[0,1]、y∈[0,2]、z∈[0,3] | 有一个面在 x=0 |
| B | 与 A 同尺寸，整体平移到 x∈[1,2] | 没有面在 x=0 |
| C | 三个 1 × 2 × 1 m 长方体沿 z 叠放，x∈[0,1] | 三个实体，fragment 后共 16 个面 |
| D | 两个 1 × 2 × 1 m 长方体沿 z 叠放，x∈[0,1] | 两个实体，fragment 后共 11 个面 |
| E | L 形弯头，单实体，y∈[0,1]；竖直段 x∈[1,2]、z∈[0,3]，水平段 x∈[2,4]、z∈[0,1] | 共 8 个面；真实入口是 z=3 的面，真实出口是 x=4 的面 |

测试里用面心坐标找面编号，不写死编号。

## 3. 测试点

### 3.1 自动识别

| 编号 | 输入 | 预期 |
|---|---|---|
| T2-01 | 几何 A，无标注 | 6 个面都有类型；z=3 为 inlet，z=0 为 outlet，x=0 为 symmetry，其余 3 个为 walls；多孔体为空 |
| T2-02 | 几何 B，无标注 | inlet 1 个，outlet 1 个，walls 4 个；没有 symmetry |
| T2-03 | 几何 C，无标注 | inlet 1、outlet 1、interface 2、symmetry 3、walls 9；多孔体只有中间那个体（z∈[1,2]） |
| T2-04 | 几何 D，无标注 | inlet 1、outlet 1、interface 1、symmetry 2、walls 6；多孔体为空 |
| T2-05 | 几何 E，无标注 | z=3 为 inlet；z=0 被猜成 outlet，x=4 被猜成 walls（已知限制，结果是错的，需要标注修正） |

### 3.2 标注覆盖

| 编号 | 输入 | 预期 |
|---|---|---|
| T2-06 | 几何 E，标注把 z=0 的面改成 walls、x=4 的面改成 outlet | inlet 1、outlet 1、walls 6；没标注的面保持自动识别结果 |
| T2-07 | 几何 D，标注 `"多孔体"` 指定下面那个体 | 多孔体只有被指定的体；面类型不变 |
| T2-08 | 几何 C，标注 `"多孔体"` 指定最上面那个体 | 多孔体只有最上面那个体，中间体不再是多孔体 |
| T2-09 | 标注里有不存在的面编号、不存在的体编号、不支持的类型（如定壁温）、格式损坏的 JSON | 报错，信息里指出是哪一项；不进入第 3 步，不留下半成品产物 |
| T2-10 | 几何 E 的标注写出为 `标注.json` 再读回 | 读回后的面类型和多孔体与写出前完全一致；面编号不因 JSON 键变成字符串而对不上 |

### 3.3 工况字典

| 编号 | 输入 | 预期 |
|---|---|---|
| T2-11 | 几何 A，工况字典给全入口速度、入口温度、出口表压、物性、壁面滑移或无滑移 | 通过；每个 inlet 面都有速度和温度，每个 outlet 面都有表压 |
| T2-12 | 几何 A，分别去掉入口速度、入口温度、出口表压 | 三种情况都报错，信息里指出缺的是哪一项 |
| T2-13 | 几何 C，工况字典给全多孔阻力和换热参数 | 通过；参数挂在中间体上 |
| T2-14 | 几何 C，工况字典不给多孔阻力或换热参数 | 报错，信息里指出缺的是哪一项 |
| T2-15 | 几何 A，入口速度为负数或非数值，入口温度为 0 K 以下 | 报错；不进入第 3 步 |

### 3.4 可重复性

| 编号 | 输入 | 预期 |
|---|---|---|
| T2-16 | 几何 C 连续识别两次 | 两次的面类型、多孔体完全一致 |

## 4. 完成标准

- T2-01 至 T2-16 全部通过。
- 失败用例（T2-09、T2-12、T2-14、T2-15）以报错结束，不能静默通过。
- T2-05 记录的是已知限制，预期值就是那个错误的猜测结果；规则改了要同步改这一条。
- 测试不依赖 OpenFOAM，也不需要划分网格，只需要能读 STEP 的环境。
