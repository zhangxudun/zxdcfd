# 第 2 步测试需求：拿到边界条件

> 对应 [工作流程](工作流程.md) 第 2 步。
> 产物：`标注.json`、工况字典。通过条件：每个外表面都有类型，入口和出口有数值。
> 实现：`generate_boundary.py`。测试：`tests/test_generate_boundary.py`。

## 1. 范围

- 测：面类型自动识别、多孔体自动识别、标注覆盖、把内部面标成边界时报错、`标注.json` 读写、工况字典数值是否齐全。
- 不测：STEP 读入和 fragment（第 1 步）、有没有 inlet/outlet 面（第 3 步）、网格（第 4 步）。

## 2. 测试几何

| 编号 | 几何 | 说明 |
|---|---|---|
| A | 长方体 1 × 2 × 3 m，单实体，x∈[0,1]、y∈[0,2]、z∈[0,3] | 有一个面在 x=0，且 x=0 是模型最小 x |
| B | 与 A 同尺寸，整体平移到 x∈[1,2] | 没有面在 x=0 |
| C | 三个 1 × 2 × 1 m 长方体沿 z 叠放，x∈[0,1] | 三个实体，fragment 后共 16 个面 |
| D | 两个 1 × 2 × 1 m 长方体沿 z 叠放，x∈[0,1] | 两个实体，fragment 后共 11 个面 |
| E | L 形弯头，单实体，y∈[0,1]；竖直段 x∈[1,2]、z∈[0,3]，水平段 x∈[2,4]、z∈[0,1] | 共 8 个面；真实入口是 z=3 的面，真实出口是 x=4 的面 |
| F | 与 A 同尺寸，整体平移到 x∈[-1,0] | 有一个面在 x=0，但 x=0 是模型最大 x |

测试里用面心坐标找面编号，不写死编号。

## 3. 测试点

### 3.1 自动识别

自动识别按下面的顺序判断，先命中的生效：

1. 两个体共用的面是 interface。它是内部面，不算外表面，也不写进 `标注.json`。
2. 位于 x=0 且 x=0 是模型最小 x 的平面是 symmetry。
3. 最高的水平面是 inlet。
4. 最低的水平面是 outlet。
5. 其余是 walls。

几何里恰好有三个体时，按中心高度排在中间的体被猜成多孔体。

| 编号 | 输入 | 预期 |
|---|---|---|
| T2-01 | 几何 A，无标注 | 6 个面都有类型；z=3 为 inlet，z=0 为 outlet，x=0 为 symmetry，其余 3 个为 walls；多孔体为空 |
| T2-02 | 几何 B，无标注 | inlet 1 个，outlet 1 个，walls 4 个；没有 symmetry |
| T2-03 | 几何 C，无标注 | inlet 1、outlet 1、interface 2、symmetry 3、walls 9；多孔体只有中间那个体（z∈[1,2]） |
| T2-04 | 几何 D，无标注 | inlet 1、outlet 1、interface 1、symmetry 2、walls 6；多孔体为空 |
| T2-05 | 几何 E，无标注 | z=3 为 inlet；z=0 被猜成 outlet，x=4 被猜成 walls（已知限制，结果是错的，需要标注修正） |
| T2-17 | 几何 F，无标注 | x=0 的面为 walls，不是 symmetry；inlet 1 个，outlet 1 个，walls 4 个 |

### 3.2 标注覆盖

标注格式是 `{"面": {面编号: 类型}, "多孔体": [体编号]}`，可以传字典或 JSON 文件路径。面类型只能是 inlet、outlet、symmetry、walls。给了 `"多孔体"` 就整体替换自动猜测的结果，不是追加。

| 编号 | 输入 | 预期 |
|---|---|---|
| T2-06 | 几何 E，标注把 z=0 的面改成 walls、x=4 的面改成 outlet | inlet 1、outlet 1、walls 6；没标注的面保持自动识别结果 |
| T2-07 | 几何 D，标注 `"多孔体"` 指定下面那个体 | 多孔体只有被指定的体；面类型不变 |
| T2-08 | 几何 C，标注 `"多孔体"` 指定最上面那个体 | 多孔体只有最上面那个体，中间体不再是多孔体 |
| T2-09 | 标注里有不存在的面编号、不存在的体编号、不支持的类型（如定壁温）、格式损坏的 JSON | 报错，信息里指出是哪一项；不进入第 3 步，不留下半成品产物 |
| T2-10 | 几何 E 的标注写出为 `标注.json` 再读回 | 读回后的面类型和多孔体与写出前完全一致；面编号不因 JSON 键变成字符串而对不上 |
| T2-18 | 几何 C，标注把 z=1 的内部面改成 inlet 或 walls | 报错，信息里说明是内部面并指出面编号；不进入第 3 步，不留下半成品产物 |

### 3.3 工况字典

工况字典的键名和单位见 `generate_boundary.py` 文件头。数值范围：

- 入口速度、入口温度、工作压力、摩尔质量、比热、湍流普朗特数、横向倍数、壁温必须大于 0。
- 湍流粘度、粘性阻力系数、惯性阻力系数、`h_av` 不能为负。
- 出口表压、体积热源只要求是有限数。
- `多孔` 只在有多孔体时必填。

| 编号 | 输入 | 预期 |
|---|---|---|
| T2-11 | 几何 A，工况字典给全入口速度、入口温度、出口表压、物性、壁面滑移或无滑移 | 通过；`标注.json` 里 6 个外表面都有类型；返回的工况里有入口速度、入口温度和出口表压 |
| T2-12 | 几何 A，分别去掉入口速度、入口温度、出口表压 | 三种情况都报错，信息里指出缺的是哪一项 |
| T2-13 | 几何 C，工况字典给全多孔阻力和换热参数 | 通过；多孔体是中间体；返回的工况里保留多孔参数 |
| T2-14 | 几何 C，工况字典不给多孔阻力或换热参数 | 报错，信息里指出缺的是哪一项 |
| T2-15 | 几何 A，入口速度为 0、负数或非数值，入口温度不大于 0 K | 报错，信息里指出是哪一项；不进入第 3 步 |

### 3.4 可重复性

| 编号 | 输入 | 预期 |
|---|---|---|
| T2-16 | 几何 C 连续识别两次 | 两次的面类型、多孔体完全一致 |

## 4. 完成标准

- T2-01 至 T2-18 全部通过。
- 失败用例（T2-09、T2-12、T2-14、T2-15、T2-18）以报错结束，不能静默通过。
- T2-05 记录的是已知限制，预期值就是那个错误的猜测结果；规则改了要同步改这一条。
