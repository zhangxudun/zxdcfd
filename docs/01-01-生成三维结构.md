# 01-01 测试需求：生成三维结构

> 属于 [工作流程](工作流程.md) 第 1 步：按参数生成 `模型.step`，再交给第 1 步读入。
> 读入部分的测试见 [01-拿到三维几何](01-拿到三维几何.md)。

本文分两层：第 3 节是通用规则，对任何结构都一样；第 4 节是结构清单，每种结构一张“结构卡片”，写明这种结构的参数和各项预期值。新增一种结构只需要加一张卡片，通用规则不用改。

## 1. 范围

- 测：按参数生成 STEP、参数校验、实体个数、体积、面数、位置、单位、交界面共用、重复生成。
- 不测：STEP 读入功能本身（01）、面类型和多孔体识别（第 2 步）、网格（第 4 步）。
- 本文读回 STEP 只是为了量尺寸，不是测读入功能。

## 2. 判定约定

对所有结构生效。

### 2.1 在哪里量

- 所有几何量都在读回的 STEP 上量，不用生成函数的返回值。
- 读回时单位取 m。
- 读回后按第 1 步的做法对多个实体做 fragment，然后再数面、量面积、找共用面。

### 2.2 怎么认实体

- 每张结构卡片给每个实体一个“内部参考点”。包含这个点的实体就是对应的那一段。
- 参考点用参数的公式给出，参数变了参考点跟着变。

### 2.3 怎么认面

- 卡片用“所在平面 + 范围”描述一个面，例如“z=6.2，x 为 0 到 3，y 为 2 到 6”。
- 面的所有顶点都在这个平面上，且包围盒与给出的范围一致，就认为是这个面。

### 2.4 容差

- 体积、面积：相对误差 ≤ 1e-6。
- 坐标、包围盒：绝对误差 ≤ 1e-3 m。
- 理论体积用卡片里的公式算，不用表里的近似小数。

### 2.5 用词

- “一致”：个数完全相等，体积、面积、坐标在 2.4 的容差内。
- “不生成文件”：目标路径原来没有文件的，报错后仍然没有；原来有文件的，报错后内容不变。
- “声明值”：结构卡片里写的预期值。

### 2.6 所有结构共同的要求

- 坐标单位 m。
- 相邻实体的交界面共用，不重复。
- 卡片参数表里标为必填的参数都必须给出，且是大于 0 的有限数。
- 参数值必须是数字类型。数字字符串（例如 `"3.0"`）和布尔值都按非数字处理。
- 只接受卡片参数表里列出的参数名，多给的参数名报错。
- 输出文件名只用英文字母、数字、下划线、连字符，不能为空。这条只限制文件名，不限制所在目录。
- 输出文件名不带扩展名，生成时自动加 `.step`。带了扩展名（例如 `a.step`）按含非法符号处理。
- 输出目录不存在时自动创建。

### 2.7 测试点编号

- 格式：`T1-01-<结构号>-<规则号>`，例如 `T1-01-S1-G02`。
- 一条规则有多个小项时加字母，例如 `T1-01-S2-G15a`。
- 对整个清单只测一次的小项，结构号写 `ALL`，例如 `T1-01-ALL-G15c`。

### 2.8 生成接口

- 入口函数：`generate_step(结构号, 参数, 输出目录, 文件名)`，成功时返回生成的文件路径 `<输出目录>/<文件名>.step`。
- `参数` 是字典，键是卡片参数表里的参数名。
- `默认参数(结构号)` 返回该结构默认参数的副本。
- 参数缺失、非法、违反约束或结构号不在清单里时，抛 `参数错误`；文件名不合规时，抛 `文件名错误`。两者都是 `ValueError` 的子类。

## 3. 通用规则

没有特别说明时，输入都是该结构的默认参数。

| 规则 | 输入 | 预期 |
|---|---|---|
| G01 | 默认参数 | 生成成功，STEP 文件非空；实体数等于声明值 |
| G02 | 默认参数 | 每个实体的体积与卡片里的理论值一致 |
| G03 | 默认参数 | fragment 前后实体数相同，总体积一致（说明实体之间没有重叠） |
| G04 | 默认参数 | fragment 后的面数等于声明值 |
| G05 | 默认参数 | 包围盒与声明值一致 |
| G06 | 默认参数 | 入口面、出口面各恰有一个，位置和面积与声明值一致 |
| G07 | 默认参数 | 同时属于两个实体的面，个数等于声明值，位置和面积与声明值一致 |
| G08 | 默认参数 | 整体位于对称面上的面，个数和面积合计与声明值一致；没有对称面的结构，个数为 0 |
| G09 | 默认参数 | STEP 文件里声明的长度单位是 m，不是 mm；按 m 读回后包围盒与 G05 相同，没有放大或缩小 1000 倍 |
| G10 | 卡片里的“改参数用例” | 卡片列出的实体体积按公式变化，其余实体体积不变；包围盒和共用面位置与卡片一致 |
| G11a | 逐个去掉一个必填参数 | 每种情况都报错，报错信息里有该参数的名字；不生成文件 |
| G11b | 逐个把一个参数改成 0、负数、非数字（含数字字符串、布尔值）、NaN、无穷大 | 每种情况都报错，报错信息里有该参数的名字；不生成文件 |
| G11c | 多给一个卡片参数表里没有的参数名 | 报错，报错信息里有该参数的名字；不生成文件 |
| G12 | 卡片里的“违反约束用例”，逐个测 | 每种情况都报错，报错信息与卡片要求一致；不生成文件 |
| G13 | 卡片里的“边界值用例” | 生成成功，结果与卡片一致 |
| G14a | 文件名含中文；含空格；含 `_`、`-` 以外的符号；带扩展名（例如 `a.step`）；为空 | 每种情况都报错；不生成文件 |
| G14b | 文件名为 `test_duct-01`；输出目录名含中文；输出目录原先不存在 | 生成成功，STEP 文件非空 |
| G15a | 同一进程内，同一组参数、同一文件名连续生成两次 | 第二次成功并覆盖文件；两次的实体数、面数、体积、包围盒一致，并且都满足 G01、G02、G04、G05 |
| G15b | 同一进程内，先用非法参数触发报错，再用默认参数生成 | 第二次成功，结果满足 G01、G02、G04、G05 |
| G15c | 同一进程内，把清单里的结构依次各生成一次，再回头生成第一种 | 每次的结果都与单独生成时一致。对整个清单只测一次 |

卡片里某条规则写“不适用”的，这条规则对该结构不测。

### 4.0 结构卡片模板

每张卡片按下面的顺序写，一项都不能少，没有的写“无”或“不适用”。

| 项目 | 内容 | 对应规则 |
|---|---|---|
| 说明 | 形状、全模型还是对称半模型、流动方向、坐标原点放在哪里 | 无 |
| 参数表 | 参数名、默认值、是否必填 | G11 |
| 约束 | 参数之间的限制；等于边界值时是否允许 | G12、G13 |
| 实体表 | 实体名、内部参考点、体积公式、默认体积 | G01、G02、G03 |
| 面数 | fragment 后的面数，并写出是怎么数出来的 | G04 |
| 包围盒 | x、y、z 的范围 | G05、G09 |
| 入口面、出口面 | 所在平面、范围、面积 | G06 |
| 共用面 | 个数；每个的所在平面、范围、面积 | G07 |
| 对称面 | 所在平面；面的个数、面积合计 | G08 |
| 改参数用例 | 改哪个参数、改成多少、预期数值 | G10 |
| 违反约束用例 | 逐条列出输入和报错要求 | G12 |
| 边界值用例 | 输入和预期数值 | G13 |
| 第 2 步自动识别 | 第 2 步的自动规则对这种结构是否成立；不成立时写明要手工标注哪些面和体 | 无 |

### 4.1 S1 直段管束

**说明**

- 入口直段 + 管束 + 出口直段，三个长方体沿 z 叠放。对应省煤器简化模型。
- 全宽模型，x 从 -半宽x 到 +半宽x，没有对称面。
- 管束底面在 z=0，入口段在管束上方，出口段在管束下方，烟气沿 -z 流动。

**参数表**

| 参数 | 默认值 | 必填 |
|---|---|---|
| 半宽x | 6.0 | 是 |
| 深度y | 8.0 | 是 |
| 管束高度 | 3.2 | 是 |
| 入口段长度 | 3.0 | 是 |
| 出口段长度 | 4.0 | 是 |

**约束**：无。

**实体表**

| 实体 | 内部参考点 (x, y, z) | 默认参考点 | 体积公式 | 默认体积 m³ |
|---|---|---|---|---|
| 入口段 | (0, 深度y/2, 管束高度 + 入口段长度/2) | (0, 4, 4.7) | 2 × 半宽x × 深度y × 入口段长度 | 288.0 |
| 管束 | (0, 深度y/2, 管束高度/2) | (0, 4, 1.6) | 2 × 半宽x × 深度y × 管束高度 | 307.2 |
| 出口段 | (0, 深度y/2, -出口段长度/2) | (0, 4, -2.0) | 2 × 半宽x × 深度y × 出口段长度 | 384.0 |

**声明值**

| 项目 | 声明值 |
|---|---|
| 实体数 | 3 |
| 面数 | 16（6 + 6 + 6，两个交界面各算一次） |
| 包围盒 | x 为 -6 到 6，y 为 0 到 8，z 为 -4 到 6.2 |
| 入口面 | z=6.2，x 为 -6 到 6，y 为 0 到 8，面积 96 m² |
| 出口面 | z=-4，x 为 -6 到 6，y 为 0 到 8，面积 96 m² |
| 共用面 | 2 个，位于 z=0 和 z=3.2，x 为 -6 到 6，y 为 0 到 8，每个 96 m² |
| 对称面 | 无；位于 x=0 平面的面数为 0 |

**用例**

| 项目 | 输入 | 预期 |
|---|---|---|
| 改参数用例（G10） | 管束高度由 3.2 改为 5.0 | 管束体积 480 m³；入口段 288.0、出口段 384.0 不变；包围盒 z 为 -4 到 8.0；共用面位于 z=0 和 z=5.0 |
| 违反约束用例（G12） | 不适用 | 不适用 |
| 边界值用例（G13） | 不适用 | 不适用 |

**第 2 步自动识别**：成立。最高水平面是入口，最低水平面是出口，三个实体里中间的是管束。

### 4.2 S2 变截面管束

**说明**

- 入口渐扩段 + 管束 + 出口收缩段，沿 z 叠放。用来测试非长方体形状，不代表真实设备。
- x=0 对称半模型，x 从 0 到 半宽x。
- 管束底面在 z=0，入口段在管束上方，出口段在管束下方，烟气沿 -z 流动。
- 入口、出口的开口在 y 方向居中，x 方向贴着对称面。

**参数表**

| 参数 | 默认值 | 必填 |
|---|---|---|
| 半宽x | 6.0 | 是 |
| 深度y | 8.0 | 是 |
| 管束高度 | 3.2 | 是 |
| 入口段长度 | 3.0 | 是 |
| 出口段长度 | 4.0 | 是 |
| 入口半宽x | 3.0 | 是 |
| 入口深度y | 4.0 | 是 |
| 出口半宽x | 2.0 | 是 |
| 出口深度y | 3.0 | 是 |

**约束**

- 入口半宽x、出口半宽x 不大于 半宽x。
- 入口深度y、出口深度y 不大于 深度y。
- 等于时允许。

**体积公式**

两个平行矩形 a1 × b1、a2 × b2 之间直线过渡、高为 h 的过渡段：

    过渡段体积(a1, b1, a2, b2, h) = h / 6 × (2·a1·b1 + 2·a2·b2 + a1·b2 + a2·b1)

**实体表**

| 实体 | 内部参考点 (x, y, z) | 默认参考点 | 体积公式 | 默认体积 m³ |
|---|---|---|---|---|
| 入口段 | (入口半宽x/2, 深度y/2, 管束高度 + 入口段长度/2) | (1.5, 4, 4.7) | 过渡段体积(半宽x, 深度y, 入口半宽x, 入口深度y, 入口段长度) | 84.0 |
| 管束 | (半宽x/2, 深度y/2, 管束高度/2) | (3, 4, 1.6) | 半宽x × 深度y × 管束高度 | 153.6 |
| 出口段 | (出口半宽x/2, 深度y/2, -出口段长度/2) | (1, 4, -2.0) | 过渡段体积(半宽x, 深度y, 出口半宽x, 出口深度y, 出口段长度) | 284/3 ≈ 94.6667 |

**声明值**

| 项目 | 声明值 |
|---|---|
| 实体数 | 3 |
| 面数 | 16（6 + 6 + 6，两个交界面各算一次） |
| 包围盒 | x 为 0 到 6，y 为 0 到 8，z 为 -4 到 6.2 |
| 入口面 | z=6.2，x 为 0 到 3，y 为 2 到 6，面积 12 m² |
| 出口面 | z=-4，x 为 0 到 2，y 为 2.5 到 5.5，面积 6 m² |
| 共用面 | 2 个，位于 z=0 和 z=3.2，x 为 0 到 6，y 为 0 到 8，每个 48 m² |
| 对称面 | x=0 平面；3 个面，面积合计 65.6 m²（入口段 18、管束 25.6、出口段 22） |

**用例**

| 项目 | 输入 | 预期 |
|---|---|---|
| 改参数用例（G10） | 管束高度由 3.2 改为 5.0 | 管束体积 240 m³；入口段 84.0、出口段 284/3 不变；包围盒 z 为 -4 到 8.0；共用面位于 z=0 和 z=5.0 |
| 违反约束用例（G12） | 入口半宽x 改为 7.0；入口深度y 改为 9.0；出口半宽x 改为 7.0；出口深度y 改为 9.0。每次只改一个 | 报错，报错信息指出是入口还是出口 |
| 边界值用例（G13） | 入口半宽x 取 6.0、入口深度y 取 8.0，其余默认 | 生成成功；入口段体积 144 m³；实体数 3，面数 16；入口面面积 48 m² |

**第 2 步自动识别**：成立。最高水平面是入口，最低水平面是出口，x=0 的平面是对称面，三个实体里中间的是管束。

### 4.3 新增结构

按附录的步骤加一节，编号顺延为 S3、S4，并在本节开头的清单表里加一行。

## 5. 完成标准

- 清单里每种结构的 G01 至 G15 全部通过，卡片里写“不适用”的除外。
- 失败用例（G11、G12、G14a）以报错结束，不能静默通过。
- 每种结构的输出都能通过 [01-拿到三维几何](01-拿到三维几何.md) 的通过条件：至少一个实体，单位为 m。
- 测试不依赖 OpenFOAM，只需要能读写 STEP 的环境。

## 附录：新增一种结构的步骤

1. 分配结构号，在第 4 节的清单表里加一行。
2. 按 4.0 的模板写卡片，每一项都要填。
3. 实体表里的默认体积按公式手算一遍，并写出公式，不要只写数字。
4. 每个实体的内部参考点用参数公式给出，并确认参数在允许范围内变化时，这个点始终在实体内部。
5. 入口面、出口面直接写明位置，不要依赖“最高、最低水平面”这类假设。
6. 参数之间没有约束的，G12、G13 写“不适用”。
7. 写明第 2 步的自动识别对这种结构是否成立。不成立的，写明要手工标注哪些面和体。
8. 对新结构跑一遍 G01 至 G15，再跑一次 G15c。
