# 01-01 测试需求：生成三维结构

> 属于 [工作流程](工作流程.md) 第 1 步：按参数生成 `模型.step`，再交给第 1 步读入。
> 读入部分的测试见 [01-拿到三维几何](01-拿到三维几何.md)。

## 1. 范围

- 测：按参数生成 STEP、参数校验、实体个数、体积、面数、位置、单位、交界面共用。
- 不测：STEP 读入（01）、面类型和多孔体识别（第 2 步）、网格（第 4 步）。

## 2. 要生成的结构

| 编号 | 结构 | 参数 | 实体数 |
|---|---|---|---|
| S1 | 直段管束：入口直段 + 管束 + 出口直段，全宽模型，x 从 -半宽x 到 +半宽x | 半宽x、深度y、管束高度、入口段长度、出口段长度 | 3 |
| S2 | 变截面管束：入口渐扩段 + 管束 + 出口收缩段，x=0 对称半模型，x 从 0 到 半宽x | S1 的参数，加上入口半宽x、入口深度y、出口半宽x、出口深度y | 3 |

共同约定：

- 坐标：x 宽度，y 深度，z 高度，单位 m，烟气沿 -z 流动。
- 管束底面在 z=0，入口段在管束上方，出口段在管束下方。
- 三个实体的交界面共用，不重复。
- S2 的入口、出口开口在 y 方向居中，x 方向贴着对称面。
- 输出文件名只用英文和数字。

默认参数：

| 参数 | S1 | S2 |
|---|---|---|
| 半宽x | 6.0 | 6.0 |
| 深度y | 8.0 | 8.0 |
| 管束高度 | 3.2 | 3.2 |
| 入口段长度 | 3.0 | 3.0 |
| 出口段长度 | 4.0 | 4.0 |
| 入口半宽x × 入口深度y | 无 | 3.0 × 4.0 |
| 出口半宽x × 出口深度y | 无 | 2.0 × 3.0 |

默认参数下的理论体积（m³）：

| 实体 | S1 | S2 |
|---|---|---|
| 入口段 | 288.0 | 84.0 |
| 管束 | 307.2 | 153.6 |
| 出口段 | 384.0 | 94.667 |

S2 的渐扩段和收缩段体积按两个平行矩形 a1 × b1、a2 × b2 之间直线过渡计算：

    体积 = h / 6 × (2·a1·b1 + 2·a2·b2 + a1·b2 + a2·b1)

## 3. 测试点

| 编号 | 输入 | 预期 |
|---|---|---|
| T1-01-01 | S1 默认参数 | 生成成功，STEP 文件非空；实体数 3；三个体积与理论值相对误差 ≤ 1e-3；面数 16 |
| T1-01-02 | S2 默认参数 | 生成成功，STEP 文件非空；实体数 3；三个体积与理论值相对误差 ≤ 1e-3；面数 16 |
| T1-01-03 | S1、S2 默认参数 | 包围盒：S1 的 x 为 -6 到 6，S2 的 x 为 0 到 6；两者 y 为 0 到 8，z 为 -4 到 6.2 |
| T1-01-04 | S1、S2 默认参数 | 最高水平面面积：S1 为 96 m²，S2 为 12 m²；最低水平面面积：S1 为 96 m²，S2 为 6 m² |
| T1-01-05 | S1、S2 默认参数 | 恰有 2 个面同时属于两个实体，位于 z=0 和 z=3.2；每个面积 S1 为 96 m²，S2 为 48 m² |
| T1-01-06 | S1、S2 的输出再按 m 读入 | 尺寸与参数一致，没有放大 1000 倍 |
| T1-01-07 | 管束高度由 3.2 改为 5.0，其余不变 | 管束体积按比例变化，入口段和出口段体积不变 |
| T1-01-08 | 缺少必填参数；任一尺寸 ≤ 0 | 报错并指出是哪个参数；不生成文件 |
| T1-01-09 | S2 的入口或出口开口大于管束截面 | 报错；不生成文件 |
| T1-01-10 | 文件名含中文 | 报错；不生成文件 |
| T1-01-11 | 同一组参数连续生成两次 | 两次的实体数、面数、体积一致 |

## 4. 完成标准

- T1-01-01 至 T1-01-11 全部通过。
- S1、S2 的输出都能通过 [01-拿到三维几何](01-拿到三维几何.md) 的通过条件：至少一个实体，单位为 m。
- 测试不依赖 OpenFOAM。
